Spreadsheets for Node.js.
Powered by Rust.

Read, write, and stream XLSX and CSV files with an ExcelJS-compatible API. Use familiar workbook objects, with parsing and compression handled by Rust.

npm install exceljs-rsGet startedAPI reference

New in 0.2.0

Control large XLSX reads with optional resource limits, cancellation, and progress. Await bulk row exports with writeRows and consume native value batches with readBatches. Existing ExcelJS API defaults remain unchanged. See the release notes and examples.

Workbook editing

Work with worksheets, rows, cells, styles, merges, formulas, tables, and images.

ExcelJS compatibility

The API targets ExcelJS 4.4.0. Review known differences and run your application's tests when migrating.

Streaming APIs

Commit rows as you write and iterate over rows as you read. Memory usage depends on the file and the options you choose.

TypeScript included

Use the shipped declarations for workbook objects, cell values, styles, and read and write options.

Create a workbook

const {Workbook} = require('exceljs-rs');

async function main() {
  const workbook = new Workbook();
  const sheet = workbook.addWorksheet('Sales');
  sheet.addRow(['Item', 'Amount']);
  sheet.addRow(['Notebook', 12.5]);
  sheet.getRow(1).font = {bold: true};
  await workbook.xlsx.writeFile('sales.xlsx');
}

main().catch(error => {
  console.error(error);
  process.exitCode = 1;
});

Save as example.cjs and run node example.cjs. The guide covers installation, reading files, streaming, CSV, and migration.

Runtime and platforms

Node.js 22 or later. Release targets: Linux x64 and arm64 (glibc), macOS x64 and arm64, and Windows x64. A native addon is required; browsers are not supported.

Performance

See the measurements and reproduction steps for XLSX and CSV workloads. Performance depends on your input and environment.

Handling uploads

Untrusted workbooks require process memory and time limits. See the security guidance before accepting uploads.
